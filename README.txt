ARQMS PORTAL (AUSGRAM-I) — ANDROID .APK CLOUD BUILD GUIDE
(NO ANDROID STUDIO NEEDED — BUILDS FREE ON GITHUB IN 3 MINUTES!)
========================================================================

STEP 1: CREATE A NEW GITHUB REPOSITORY
  1. Go to https://github.com/new (logged in as skashik1608-blip).
  2. Repository name: arqms-ausgram1-android
  3. Choose Public (or Private — GitHub Actions works on both).
  4. Click "Create repository".

STEP 2: UPLOAD THIS EXTRACTED FOLDER TO GITHUB
  1. Extract ARQMS_Ausgram1_Android_App.zip on your PC.
  2. Open the extracted "ARQMS_Ausgram1_Android_App" folder.
  3. On GitHub, click "uploading an existing file" (on the empty repo page).
  4. Drag & drop ALL files and folders inside "ARQMS_Ausgram1_Android_App"
     (.github, app, build.gradle, gradle.properties, settings.gradle, README.txt)
     and click "Commit changes".
     NOTE: Make sure the ".github" folder is uploaded! (In Windows Explorer,
     enable View -> Show -> Hidden items if you don't see ".github".)

STEP 3: DOWNLOAD YOUR READY ANDROID .APK (3 MINUTES)
  1. Click the "Actions" tab at the top of your GitHub repository.
  2. Click the running workflow "Build ARQMS Android APK".
  3. Wait ~2-3 minutes until you see a green checkmark.
  4. Scroll down to "Artifacts" -> click "ARQMS-Ausgram1-Android-APK" to download!
  5. Unzip it to get "ARQMS-Ausgram1-Mobile-v1.0.0.apk".
  6. Send it via WhatsApp/USB to any Android phone and tap to install!

AUTO-UPDATES:
  Because this app loads your live ARQMS Portal URL with automatic cache
  refresh, every time you update Google Apps Script
  (Deploy -> Manage deployments -> Edit -> New version -> Deploy),
  ALL Android phones get the latest ARQMS features automatically!
